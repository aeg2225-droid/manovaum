Сайт для пар · JavaScript · GitHub Pages+

Романтический сервис, где двое хранят общие истории и письма. Письма спрятаны в конвертах: каждый открывается в своё время.

  • Один логин на пару, не больше двух участников.
  • Отдельная база историй у каждой пары и синхронизация в реальном времени.
  • Админ-панель, где управляют письмами и фото с телефона.
  • Разделы: история, купоны, список мечт, альбом, квиз, плейлист, особые даты.

Dota Stats Bot PRO

Discord-бот · Python+

Бот для игроков в Dota 2: помогает на драфте и показывает статистику прямо в Discord, без переключения между сайтами.

  • /counter: подбор контрпиков к герою соперника.
  • /draft: подсказки во время пика героев.
  • /build: сборки предметов.
  • /live и /stats: матчи в эфире и статистика игроков.
Стек
Python, Discord API
Запуск
Windows 10/11, с инструкцией по установке
